Чтобы запустить игру:

WINDOWS:

ЗАПУСТИТЬ ФАЙЛ Labyrinth.exe

Если возникли какие-либо ошибки, перекомпилируйте игру:
_________________________________________________________________________________________________________
1. Нажмите правой кнопкой мыши по пустому месту в папке с игрой и выберите "Открыть в терминале"

ИЛИ

Самостоятельно откройте CMD и перейдите в папку с игрой 
_________________________________________________________________________________________________________
2. Находясь в папке с игрой напишите в командную строку по очереди 
    - make clean
    - make 


после чего снова запустите файл labyrinth.exe
